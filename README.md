# Phoenix FBI — Delta Green

Campaign website for a Delta Green tabletop RPG campaign.

**URL:** https://medesen.github.io/delta-green-phoenix-fbi/

## Editing content

All page content lives in the `content/` folder as plain markdown files. To edit a page, go to that file on GitHub and click the pencil icon. Changes go live within ~30 seconds.

## Adding files (handouts, maps, images)

Drop files into the appropriate subfolder under `assets/`, then link to them in the relevant `content/` markdown file.
